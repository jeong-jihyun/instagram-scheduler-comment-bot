Step 01 · Upload

CSV 파일 가져오기

분석할 설문 응답 파일을 선택하세요. UTF-8 CSV 형식을 지원하는 흐름으로 설계했습니다.

⇧
분석할 파일을 선택하세요

CSV · 첫 번째 행은 열 이름이어야 합니다.

개인정보로 보이는 열은 기본적으로 보고서에서 제외합니다. 탐지 기능은 보조 수단이며 모든 개인정보를 찾아내지는 못합니다.

프로토타입은 선택한 파일을 브라우저 안에서 처리합니다. 기존 CLI는 로컬 Python 명령으로 실행됩니다.

현재 분석 도구의 처리 기준과 한계를 확인할 수 있습니다.

개인정보 처리

이름·이메일·전화번호 등으로 의심되는 열은 기본 보고서에서 제외합니다.

열 이름 힌트와 이메일/휴대전화 형태를 기준으로 탐지합니다. 완전한 개인정보 식별이나 법적 비식별 처리를 보장하지 않습니다.

분석 방식

유료 AI API 또는 네트워크 호출 없이 CSV를 로컬에서 처리하는 것이 현재 CLI의 기본 방향입니다.

숫자형 평균·중앙값·최소·최대·분포

선택형 항목별 응답 빈도

주관식 단순 단어 빈도 상위 5개

CLI 실행 안내

pip install -r requirements.txt

python -m survey_report check --csv sample/survey.csv

python -m survey_report build --csv sample/survey.csv --out output
